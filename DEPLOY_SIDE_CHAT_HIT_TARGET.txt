Josh (iPhone Safari preview): "Join live chat" visible lower-left overlapping

Root cause
----------
1) `.table-side-live-chat` was `position: absolute; bottom: 5.8–6.4rem; left`
   over the hand fan. Hand-area (z14 + transform) intercepted taps even when
   the pill painted on top.
2) Same bottom-left zone sits under starter / hand chrome on wide desktop, so
   the control often looked missing on web.

Fix
---
1) Mount **Join live chat** in `.meta-leading` next to **Quit** (header left).
   Clear of hand, Confirm discard, crib prompts, starter corner.
2) CSS: `position: relative` (no absolute bottom-over-hand); `z-index: 32` on
   `.meta` / `.meta-leading` / `.table-side-live-chat`; `pointer-events: auto`;
   `.meta { overflow: visible }`; Join button `min-height: 44px` +
   `touch-action: manipulation`.
3) Desktop @900+: same header placement, slightly roomier label — visible on
   wide/desktop play view.
4) Unchanged: VAD (not PTT); Live green connected / red not; Leave;
   `SIDE_LIVE_CHAT_ENABLED` + `isSideLiveChatEnabled(hostname)` preview gate;
   legacy table Hold-to-talk stays OFF.

-----------------

   successful createOffer. Offer-retry / renegotiate paths could wipe a guest
   answer mid-write → answer stays 0 forever (Josh hypothesis confirmed in code).
2) Guest onRemoteOffer early-returned when !micAttached — and answer-retry also
   required micAttached. Ready can publish before mic; Join mic lag ⇒ never
   createAnswer ⇒ no ice/1 and no answer (matches RTDB).
3) Mid-flight race: newer offer arrived while makingAnswer=true; on finish the
   first answer path set pendingRemoteOffer=null and wroteLocalAnswer=true,
   dropping the newer offer with no retry.
4) While have-local-offer, retry previously no-op'd (not stable) OR if it did
   re-offer, cleared answer. Now: republish SAME local offer (new `at`) without
   clearing answer so late guest listeners still fire.

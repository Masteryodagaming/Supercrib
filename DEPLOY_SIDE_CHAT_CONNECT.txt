Root cause
----------
Several layered bugs in the Join → WebRTC path (not the VAD RMS math):

1) Ready-before-mic race
   Session wrote voice/ready/{seat} at start(), then adopted the Join mic.
   Host could createOffer on an empty audio transceiver; replaceTrack
   renegotiate was dropped when makingOffer was already true (early return
   without needsRenegotiate). Peer link often never reached live.

2) Join-gesture mic killed on effect teardown
   Any effect remount / bothConnected blip called dispose() which
   track.stop()'d the Safari-gesture mic. Re-ensureMic without a tap fails
   on iOS → stuck red forever while UI still showed joined.

3) Leave / clearSignaling wiped peer ready with no re-assert
   One seat’s clear of rooms/{code}/voice removed the other seat’s
   ready/{n}. Surviving session never re-wrote ready → handshake stuck
   on “Waiting for opponent…”.

4) Dead OpenRelay static TURN creds
   openrelayproject/openrelayproject is no longer the documented free
   path (Metered now requires API-key ICE fetch). Cellular / symmetric
   NAT had no working relay.

5) VAD path had no Hold-style ICE watchdog
   Legacy PTT kicked ICE restart on Hold; side chat only unmuted on
   speech and never auto-restarted a stalled link while quiet.

Fix
---
1) voicePtt.ts
   - start({ announceReady: false }) + announceReady() so side chat
     attaches mic BEFORE publishing ready (first offer has a real track).
   - start() clears stale ready/{seat} before binding.
   - Ready listener re-asserts ready/{seat} if wiped while session still
     wants chat.
   - maybeNegotiate: if makingOffer, set needsRenegotiate (don’t drop).
   - scheduleLinkWatchdog (~3.5s after both-ready) → host iceRestart once.
   - dispose(clear, { stopMic }) can preserve Join mic across remounts.
   - ICE: freeTURN (free:free) primary relay + freeturn STUN/TURNS;
     keep Google/Cloudflare STUN.

2) useSideLiveChat.ts
   - start(defer ready) → adoptMicStream → announceReady → VAD.
   - Effect cleanup preserves mic (stopMic: false) while still joined.
   - Full RTDB wipe + mic stop only via shouldFullyTeardownSideChat
     (left chat / unavailable / no code) — not transient enabled blips.

3) App.tsx
   - Pass stable session.code / session.seat (don’t null when gate
     flickers) so Join mic/signaling aren’t wiped mid-match.

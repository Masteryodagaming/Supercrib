Root cause
----------
CSS capped the pegging COUNT box:
  .table.phase-pegging .mid-play-row .play-area.peg-active {
    max-width: min(100%, 220px);
  }
Desktop pile cards are 56×78 (@900) / 62×86 (@1100) → only **3 cards** fit in 220px;
4th+ were clipped by mid-zone overflow-x:hidden (not rendered-off — DOM had full
state.peg.sequence; layout hid them).

Phone (32–36px cards): ~5–6 fit in 220px before clip — also improved by this fix.

Hidden count
------------
- Desktop: cards after the **3rd** were hidden (typically 1–N of a long sequence).

  reset). Table.tsx already mapped the full array — no engine/rules change.

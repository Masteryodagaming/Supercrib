Host / guest pick + sync
------------------------
1. Host: Find Match → Play online → Scoring mode → Normal or Competitive →
   Create room. Room record stores scoringMode; lobby shows the mode label.
2. Guest: Join room (code/link). Sees host’s Scoring: Normal/Competitive in
   waiting lobby. No chooser.
3. Host Play → cut → skins → host deal writes GameState with scoringMode.
4. Guest mirrors via subscribe; show claims / muggins push with rev check;
   both clients share the same competitiveShow state.

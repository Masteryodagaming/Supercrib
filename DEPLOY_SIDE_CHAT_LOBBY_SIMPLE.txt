New simple design (shipped)
---------------------------
1) Online lobby (both seats connected): clear **Connect voice** control.
2) Both opt in → WebRTC once in lobby (minimal path):
   - Seat 0 offers once when both lobby-voice-ready
   - Other seat answers once (offer.from !== mySeat)
   - Trickle ICE; no answer wipe on offer retry; no ready-without-session;
     publish SDP immediately (no gather-wait) — kept from prior hard fixes
3) Green Live in lobby → **same session carries into the table** (no tear-down
   on Play / cut / discard / Table remount). Leave only on Quit / Leave room /
   Disconnect voice.
4) Table: compact green/red Live + Disconnect. Mid-hand Join no longer the
   primary path (fallback Connect only if lobby was skipped).
5) VAD once live. VOICE_PTT_ENABLED stays false.
6) Hostname gate unchanged — chat OFF on live hosts.

What we simplified / removed
----------------------------
- Removed reliance on mid-hand "Join live chat" as the primary connect UX.
- Stopped disposing the PeerConnection on React effect cleanup while still
  joined (Table remounts / StrictMode / phase changes were killing the PC).
- Module-level lobby voice hold (`lobbyVoice.ts`) owns start/stop above Table.
- Lobby is now the place to Connect; table is status + Disconnect.
- Competing mid-table Join maze bypassed for the happy path (not two fighting
  systems — one session, lobby-first).
